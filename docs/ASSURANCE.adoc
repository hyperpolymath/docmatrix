= DocMatrix structured-data acceptance boundary
:revdate: 2026-11-16

The portable default package set is formatrix-core and docmatrix-data.
The historical formatrix-core package name is retained for API compatibility;
workspace repository metadata now identifies DocMatrix.

docmatrix-data provides a standalone docmatrix CLI and a Rust conversion API.
KYAML, strict JSON, explicit binary64 JCS and Dhall enter through kyq. Outputs are block KYAML, canonical
JSON plus LF, or JCS bytes without LF. Multiple documents are rejected when
the selected output can represent only one. Presentation comments and anchor
spellings are not preserved. Structured data never enters the prose AST.

Dhall evaluation time is exponential in nesting depth in serde_dhall 0.13. The
CLI runs Dhall in a worker process bounded by a wall-clock deadline on every
platform, by `RLIMIT_CPU` on Unix and by `RLIMIT_AS` on Linux (macOS rejects
lowering it, so memory is not capped there); any limit is reported as
`RESOURCE_LIMIT` (tested-only: `crates/docmatrix-data/tests/cli.rs`). The
library function `convert` does not bound Dhall; callers with untrusted Dhall
use `isolate::convert_isolated`. Windows relies on the wall-clock deadline alone.

Run cargo test --locked --all-targets, cargo test --locked --doc and
cargo clippy --locked --all-targets -- -D warnings for the portable package set.
The portable Windows tests and warnings-denied Clippy passed on 2026-11-16
against immutable kyq revision `9df66eb598093c15e4201af5c51a5b6527f8f8f2`.
The adapter has independent cross-format and CLI byte-profile/rejection regressions.
See link:../verification/PROOF-STATUS.adoc[the Creusot/Pearlite and Verus scope ledger].

The GUI, database and pipeline workspace packages remain separately selectable.
Their platform dependencies and behavior are not certified by a portable-core
job. The tabbed editor belongs to Formatrix Docs. ForthWall is still a proposal.

Open requirements: complete losslessness tests for every prose converter,
format-specific fuzzing and mutation campaigns, current taxonomy evidence,
live platform CI, offline Guix builds with a sufficient compiler, and signed
Stapeln admission. Proof claims inherit only the exact verified component
boundary; a kyq budget lemma is not a proof of document conversion.

The current follow-up pins kyq 128cb50b62d77af171d351611e2229313c29ed7a and
ijson-jcs c7091491ad48b64c19ee9bb754a28186f8e94042. Hosted validation is pending
for this revision. Earlier local results above do not cover the new reader.
The resource coordinator holds local heavy builds, proof runs and campaigns.
